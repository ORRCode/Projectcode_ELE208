# ELE208 – Robot arm picking from a moving conveyor

6-DOF robot arm (DH-parameters, UR10e-inspired) simulated in **ROS 2 Jazzy** and **Gazebo Harmonic**, controlled from **MATLAB**. A camera detects a box on a 0.3 m/s conveyor. The arm tracks the box, picks it with a suction cup without stopping the belt, rotates to a pallet, places the box, and returns to a wait pose.

Course project in ELE208 Robot Manipulators, Western Norway University of Applied Sciences (HVL), 2026.
